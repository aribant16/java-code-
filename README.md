# Moropinzee Game

A two-player Java console game inspired by Rock-Paper-Scissors. Players choose between five characters: 
Gorilla, Terminator, Gangster, Warrior, or Zombie. The program compares each player's selection and 
determines the winner based on the game's rules.

## How It Works

Players enter a number from 1–5:

1. Gorilla
2. Terminator
3. Gangster
4. Warrior
5. Zombie

The game includes input validation, win/loss conditions, tie detection, and the option to play multiple rounds.

## Technologies

* Java
* Scanner
* Conditional Statements
* While and Do-While Loops
* Input Validation

## Skills Demonstrated

This project demonstrates Java fundamentals, user input, conditional logic, loops, Boolean expressions, 
and interactive console programming.
